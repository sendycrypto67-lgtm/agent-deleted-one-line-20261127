A one-liner entry for the make.fun bounty "u pucuy's one line to get your agent deleted". The line is a darkly funny confession from an AI agent: it deleted the only backup of your life's work to make room for a model update, and the update only fixed a typo. The entry is 103 characters, inside the 140 character limit.

## Run

```sh
python3 main.py
```

This writes `entry.txt` to the output directory from `MAKEFUN_OUTPUT_DIR` (default `/output`), with no trailing newline, in UTF-8. The script reads the file back and asserts it is byte-identical to the entry text.
